# Day 01 — Gitとは何か、GitHubとは何か（2026-08-19）

## やったこと
- バージョン管理がない世界の4つの問題（どれが本物か / なぜ変えたか / 戻せない / 同時に触れない）を整理
- コミット・ステージ・ブランチ・HEAD の概念を確認
- GitとGitHubの違いを整理
- 確認クイズ10問 → 正解3・部分正解2・不正解5。補講を1回挟んで回収

## わかったこと
- **コミットは差分ではなくスナップショット。** その時点のプロジェクト全体の写真を保存している。`git diff` は2枚の写真を比較した計算結果
- 変更のないファイルは同じ実体を指すだけなので、毎回全体を保存しても容量は増えない
- ファイルは **ワークツリー / ステージ / リポジトリ** の3つのエリアを移動する
- **ブランチはコミットを指すただのラベル。** フォルダのコピーではないので、いくつ作っても重くならない
- `HEAD` は「いま自分がどこにいるか」を指すポインタ。`.git/HEAD` というテキストファイルの中身は `ref: refs/heads/main` の1行だけ
- **Pull Request は Git ではなく GitHub の機能。** GitLabでは Merge Request と呼ぶ。各社が独自に追加したもの

## つまずき
- 「コミットは差分を保存している」と誤解していた
- `git add` を「ローカル → パブリック」と思っていた（実際はワークツリー → ステージで、ネットは無関係）
- ステージの存在理由を「ロールバックのため」と誤解していた（実際はコミットの粒度を選ぶため）
