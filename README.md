## 学習の軸

AI によって誰でもアプリが作れる時代に、ビギナーとして何で差をつけるか。
**テスト・セキュリティ・監視**の 3 つを軸に据えています。

作ったものより、**わざと壊して原因を特定し、直した記録**を成果物の主役にします。
成果物リポジトリには `INCIDENT.md` を置き、次の 6 項目で残します。

- 事象
- 気づいた経路
- 調べた順番
- 原因
- 対処
- 次に備えて変えたこと
